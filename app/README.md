# Oceniator v2

Rownolegly rebuild aplikacji w React + Vite + TypeScript.

## Scripts

- `npm run dev` - lokalny serwer Vite
- `npm run build` - TypeScript + build produkcyjny
- `npm run lint` - ESLint

## Tryby danych

Domyslnie aplikacja probuje uzyc Supabase. Przycisk `Uruchom lokalne demo jako admin`
przelacza biezaca przegladarke na lokalny provider oparty o `localStorage`.
