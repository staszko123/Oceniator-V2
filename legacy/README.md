# Legacy fallback

Ten katalog przechowuje poprzedni statyczny shell aplikacji jako referencje i awaryjny fallback.
Glowne UI jest teraz budowane z aplikacji React/Vite w `app/` przez rootowe skrypty `npm run dev`
i `npm run build`.

Nie rozwijaj nowych funkcji w legacy bez wyraznej decyzji o cofnieciu migracji.
